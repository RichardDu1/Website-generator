## 一、战略转向

### 1.1 放弃 Gabagool 合成套利
清晨计划写了 Gabagool 式合成套利（同时买 YES+NO，pair_cost < 0.975）。用户实测：
- UP + DOWN ≥ $1.01（远超 $1.00 阈值）
- 加上 1.8% Crypto taker fee，机会被费用吞掉
- 竞争激烈到套利机会存活 < 1 秒

**结论**：放弃 Gabagool，彻底改走 Gengar 式方向性延迟套利。

### 1.2 Gengar 核心原理
Binance WS 实时 BTC 价格 **领先** Polymarket 订单簿重定价。当 BTC 大幅移动时，Polymarket 订单簿反应滞后几秒到几十秒，产生可套利 edge。

关键公式：
```
btc_delta_pct = (btc_now - window_opening) / window_opening * 100
effective_vol = vol * sqrt(sec_remaining / 300)
z_score = |delta_pct| / effective_vol
true_prob = 0.5 * (1 + erf(z_score / sqrt(2)))
edge = true_prob - market_price
```

4 层入场过滤：
1. `entry_window_start/end_secs`（仅在窗口最后 4 分钟交易）
2. `|delta_pct| >= min_btc_delta_pct` (0.06%)
3. `true_prob >= min_prob` (0.80)
4. `edge >= min_edge` (0.05)

Quarter-Kelly 仓位：`kelly_f = (b*p - q) / b`，`bet = bankroll * kelly_f * 0.25`，clamp 到 $5-$25。

### 8.1 数据驱动的调优信号

1. **79% 的 M5 skip 是 `delta_too_small`** → 若降 `min_btc_delta_pct` 从 0.06 → 0.04，能解锁约 3,000 个额外 evaluate 机会（但 edge 会更薄）
2. **155 次 M5 `prob_or_edge_too_low`** → `min_edge=0.05` 可能偏严，10-20 笔边缘机会被砍
3. **H4 的 `entry_window_start_secs=240`** 意味着 4h 窗口只有最后 4 分钟可入场 → 99.7% 的 H4 tick 都是 early-skip。考虑放宽到 600-900s

### 8.2 成本结构

Dry-run 下 0 手续费，PnL 是 upper bound。实盘下：
- Post-only maker = 0% fee（我们优先走这条）
- GTC taker = ~2% fee（边缘场景下降级）
- **40 trades × avg notional $15 × 2% = $12 潜在 taker 费** → 如果全走 taker，净 PnL 从 +$35.38 掉到 +$23.38（仍盈利但 34% 被吃掉）

所以 I4 的 pre-flight crossing guard 是**盈利的关键**。
